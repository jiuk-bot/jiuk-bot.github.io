에이블리 입점 중소·신규 셀러를 위한
순수 성과형 상품광고

"성과 없으면 0원." 전환(구매·쿠폰 사용·앱 설치)이 발생할 때만 과금하는 성과형 광고로 진입장벽을 낮춰 롱테일 셀러를 활성화하고, 광고비 + 증분 GMV 거래 수수료로 에이블리 총 기여를 확대하는 제품 기획.

지원 직무와 직결 — 광고 상품·수익 관점모든 수치는 파일럿 가정Manus(Manny) 기반 작성 · 윤지욱 기획
01 문제 & 해법

지금은 성과와 무관하게 과금된다. 그래서 중소·신규 셀러가 못 들어온다.

현행 에이블리 광고는 CPD(구좌제·고정가)와 oCPM(노출당 과금)이 중심 — 성과가 없어도 광고비가 소진되고, 최소 집행비가 커 중소·신규 셀러의 진입장벽이 높습니다.

현행 — CPD / oCPM
  • 기간 점유 · 노출 기준 과금
  • 전환이 없어도 광고비 소진
  • 최소 집행비 수백만~천만 원 → 진입장벽
  • "돈만 쓰고 성과 없을까" 두려움 → 시작·재집행 X
→
제안 — 순수 성과형(Pay-for-Performance)
  • 전환(구매·쿠폰·설치) 발생 시에만 과금
  • 성과 없으면 0원 → 광고주 금전 리스크 0
  • 소액으로 부담 없이 시작 → 롱테일 셀러 유입
  • 기존 인피드 지면에 과금 레이어만 추가 (신규 지면 X)

02 광고 지면 & 상품 예시

이미 전환이 활발한 인피드 상품광고 지면에 얹는다.

새 지면을 만드는 게 아니라, 전환이 잘 터지는 기존 상품광고 지면에 성과형 과금을 적용합니다.

광고
에이블리 상품 피드 예시 — 이런 지면의 상품 사이에 성과형 광고를 노출하는 목업

MVP 적용 지면 (기존)

  • 투데이 추천상품 — 홈 피드 추천 영역
  • 투데이 · 검색결과 '비슷한 상품을 찾아봤어요' — 상품 사이 인피드
  • 상품상세 '연관 추천 상품'
  • 검색 기반 신규 지면

· 과금만 성과형으로 바뀔 뿐, 노출 형태는 기존 상품광고와 동일 공개 · 유저 경험 변화 없음

과금 · 경매 · 측정 — 광고주는 리스크 0, 플랫폼은 수익 방어.

04 왜 에이블리만 가능한가

성과형은 전환을 예측·측정할 수 있어야 가능하다.

토스 ROAS 보장형의 커머스 버전. 에이블리는 성과형을 '해도 손해 안 보는' 조건을 다 갖췄습니다.

05 수익 임팩트 & 성공지표

06 리스크 & 로드맵

리스크는 가드레일로 선제 차단, 확장은 단계적으로.

  • 공짜 노출 소진 (전환 안 될 상품이 지면 점유) → eCPM 경매 + 바닥가 95/80% 가드레일, 전환 활발 카테고리부터
  • 역선택 (전환 낮은 광고주 몰림) → 판매량·평점·재고·배송 품질로 참여 자격·노출 한도 제한
  • 가짜 전환·어뷰징 → 결제자·기기 중복 제거, 환불 제외, 이상 패턴 탐지, 정산 보류
  • 자연전환 과대평가 → 기여 윈도우·중복 제거·대조군 기반 증분성 분석
  • 기존 CPD 매출 잠식 → 대형 CPD 유지, MVP는 중소·신규 셀러·한정 지면
PHASE 1 · 파일럿
패션·뷰티 한정
전환 활발 카테고리·기존 지면 + 레퍼런스 셀러 100개. "성과 없으면 0원" 메시지로 모집, 7일 리포트.
PHASE 2 · 확대
게이트 통과 시
공짜 소진율·마진·예측 정확도·재집행률이 기준 통과 → 카테고리·셀러 확대.
PHASE 3 · 검토
외부 · 보장형
외부 미입점 광고주(수수료 없음), 추가 지면, CPA 상한·전환 건수 보장 검토.
07 상세 기능 명세 & 정책 실무자용 depth

주요 기능 6종

기능핵심 요구사항
1 · 성과형 캠페인 생성·과금상품·기간·예산·목표 전환 설정. 유효 전환 확정 시에만 전환 단가로 과금, 노출·클릭만이면 0원. 취소·환불·중복·정책 위반 제외. 예산·노출·카테고리 한도 초과 시 집행 자동 제한.
2 · 전환 측정·어트리뷰션내부 결제·쿠폰 로그 + 외부 포스트백/API. 클릭 후 기여 윈도우(기본 7일), 동일 주문·쿠폰·설치 중복 과금 방지, 환불·부정 시 재계산, 자연전환 vs 광고 기여 구분 + 증분성 원천 데이터 저장.
3 · 타겟팅·예측·품질 방어카테고리·가격·행동·과거 전환으로 타겟 구성·전환 예측. 판매량·평점·재고·배송 품질로 참여 적합성 평가, 이상 패턴 탐지·캠페인 정지·전환 무효화, 지면·셀러별 공짜 소진율·예측 오차 모니터링.
4 · 광고주 성과 대시보드노출·클릭·전환·전환율·전환당 비용·과금액·잔여 예산. 전환 유형별 실적, 자연 vs 광고 기여·확정 vs 검증 대기 구분, 필터·다운로드, 전환 0 기간 과금 0원 확인·과금 근거 조회.
5 · 운영·정산·정책카테고리·지면·셀러 등급·품질·한도 설정, 전환 검증·승인·무효·환불 조정, 공짜 소진율·마진·기회비용 파일럿 기준 비교, 게이트 충족 시 확대·미달 시 자동 축소, 성과형 vs CPD 분리 집계(잠식 확인).
6 · 단계적 출시 로드맵파일럿 대상·기간·사전 KPI 승인 → 종료 후 성장·건전성 지표로 확대/유지/축소 결정. 공짜 소진율·마진 하회 시 한도 축소, 외부 광고주·CPA/건수 보장은 Phase 2, 대형 CPD는 범위 제외·유지.

프로덕트 정책 4종

전환 단가 책정 정책
3안 비교(고정 단가 / 목표 CPA 입찰 / 기준단가 자동 조정) → MVP는 카테고리 기준단가 자동 조정 채택. 파일럿 가정: 구매 4,000 · 쿠폰 1,500 · 앱설치 2,500원, 지면·상품·셀러 예측·품질로 80~120% 조정. 실제 eCPM이 기준比 10%↓ 7일 지속 시 상향, 20%↑ & 재집행률 35%↑면 인하 검토. 캠페인 생성 전 단가·예상 전환·비용 고지.
상품광고 경매 & 노출 배분 정책
성과형 eCPM = 예상전환율 × 전환단가 × 1,000, oCPM(입찰 eCPM)과 동일 랭킹 경매(eCPM + 품질점수). 예상 eCPM이 지면 바닥가 95% 미만 우선순위↓ · 80% 미만 oCPM 대체. 실제 eCPM이 예상의 80% 미만 3일 연속 → 일 노출 50% 축소. 공짜 소진율 20% 초과 → 신규 유입 중단. 셀러당 일 노출 지면의 5% 이하.
전환 확정 & 정산 정책
내부 구매·쿠폰 D+7, 외부 전환 D+14 확정. 확정 비용 매일 누적, 청구서 월 1~말일 확정분 익월 5일 발행, 발행 후 7일 이의. 유효 전환 = 기여 윈도우(기본 클릭 후 7일) 내 결제 완료·유효 쿠폰 사용. 취소·환불·부정·셀프 구매 제외, 이상 패턴은 정산 보류, 확정 후 환불은 익월 차감(크레딧 우선).
GTM & 온보딩 정책
파일럿 = 패션·뷰티 + 전환 활발 지면. 초대 대상: 최근 90일 주문 30건+, 평점 4.2+, 품절률 5% 미만. 카테고리별 20~30개, 총 100개 레퍼런스 셀러 1차 모집. 세일즈 메시지 = "성과 없으면 0원, 전환 발생분만 과금". BD가 첫 성과 사례를 같은 카테고리 셀러에 제시, 시작 후 7일 리포트·조정 제안, 성과 충족 시 30일 내 재집행 제안.
