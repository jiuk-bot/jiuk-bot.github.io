01 문제 & 해법

지금은 성과와 무관하게 과금된다. 그래서 중소·신규 셀러가 못 들어온다.

CPD·oCPM은 성과 없어도 돈이 나가고, 문턱이 높다 → 중소·신규 셀러가 못 들어온다.

구분 AS-IS 현행 · CPD / oCPM TO-BE 제안 · 순수 성과형
과금 형태노출·기간 기준 과금전환(구매·쿠폰) 시에만 과금
성과 없을 때광고비 소진0원
광고주 금전 리스크손실 가능리스크 0
최소 집행비수백만~천만 원소액 시작
진입 가능 셀러대형 위주중소·신규 셀러 유입
지면기존 인피드기존 그대로 · 과금 레이어만 추가

· 핵심은 과금 기준을 '노출·기간' → '전환'으로 바꾸는 것 — 광고주는 리스크 0, 지면·유저 경험 변화 없음

02 광고 지면 & 상품 예시

이미 전환이 활발한 인피드 상품광고 지면에 얹는다.

새 지면을 만드는 게 아니라, 전환이 잘 터지는 기존 상품광고 지면에 성과형 과금을 적용합니다.

광고
에이블리 실제 광고 지면 — 전환 중심 슬롯(예: '8천원대')에 성과형 과금을 적용

MVP 적용 지면 (기존)

  • 투데이 추천상품 — 홈 피드 추천 영역
  • 투데이 · 검색결과 '비슷한 상품을 찾아봤어요' — 상품 사이 인피드
  • 상품상세 '연관 추천 상품'
  • 검색 기반 신규 지면

· 과금만 성과형으로 바뀔 뿐, 노출 형태는 기존 상품광고와 동일 공개 · 유저 경험 변화 없음

04 왜 에이블리만 가능한가

성과형은 전환을 예측·측정할 수 있어야 가능하다.

토스 ROAS 보장형의 커머스 버전. 에이블리는 성과형을 '해도 손해 안 보는' 조건을 다 갖췄습니다.

핵심 논리광고+페이광고 매출광고 + 증분 GMV 수수료 = 총 기여

· "광고 기여 GMV"는 oCPM으로는 유입되지 않던 신규 셀러의 증분 GMV로 정의 → 그 수수료는 기존 oCPM 베이스라인에 없던 순증분. 외부 미입점 광고주는 수수료가 없어 Phase 2.

05 수익 임팩트 & 성공지표

광고 매출이 아니라 '에이블리 총 기여'로 평가한다.

총 기여 = 광고비 + (광고 기여 증분 GMV × 7% 수수료). 월 1,000만 노출 · 전환단가 4,000원 · 주문 40,000원 · 수수료 7% 가정 (인벤토리 단위 비교).

06 리스크 & 로드맵

리스크는 가드레일로 선제 차단, 확장은 단계적으로.

리스크가드레일 (선제 대응)
공짜 노출 소진전환 안 될 상품이 지면 점유eCPM 경매 + 바닥가 95/80% 가드레일, 전환 활발 카테고리부터
역선택전환 낮은 광고주 몰림판매량·평점·재고·배송 품질로 참여 자격·노출 한도 제한
저가 상품 쏠림주문금액↓ → 수수료 기여↓상품가 구간별 단가 조정, 평균 주문금액·수수료 기여 수익 가드 모니터링, 미달 카테고리 참여 제한
가짜 전환·어뷰징결제자·기기 중복 제거, 환불 제외, 이상 패턴 탐지, 정산 보류
자연전환 과대평가기여 윈도우·중복 제거·대조군 기반 증분성 분석
기존 CPD 매출 잠식대형 CPD 유지, MVP는 중소·신규 셀러·한정 지면
PHASE 1 · 파일럿
패션·뷰티 한정
전환 활발 카테고리·기존 지면 + 레퍼런스 셀러 100개. "성과 없으면 0원" 메시지로 모집, 7일 리포트.
PHASE 2 · 확대
게이트 통과 시
공짜 소진율·마진·예측 정확도·재집행률이 기준 통과 → 카테고리·셀러 확대.
PHASE 3 · 검토
외부 · 보장형
외부 미입점 광고주(수수료 없음), 추가 지면, CPA 상한·전환 건수 보장 검토.
07 상세 기능 명세 & 정책 실무자용 depth

주요 기능 6종

기능핵심 요구사항
1 · 성과형 캠페인 생성·과금상품·기간·예산·목표 전환 설정. 유효 전환 확정 시에만 전환 단가로 과금, 노출·클릭만이면 0원. 취소·환불·중복·정책 위반 제외. 예산·노출·카테고리 한도 초과 시 집행 자동 제한.
2 · 전환 측정·어트리뷰션내부 결제·쿠폰 로그 + 외부 포스트백/API. 기여 윈도우(기본 클릭 후 7일) 내 마지막 유효 클릭 1건에 귀속(last-click), 노출만 발생한 view-through는 MVP 과금 제외. 동일 주문·쿠폰 중복 과금 방지, 환불·부정 시 재계산, 자연전환 vs 광고 기여 구분 + 증분성 원천 데이터 저장.
3 · 타겟팅·예측·품질 방어카테고리·가격·행동·과거 전환으로 타겟 구성·전환 예측. 판매량·평점·재고·배송 품질로 참여 적합성 평가, 상품가 구간·카테고리 평균 주문금액·수수료 기여를 수익 가드로 모니터링(미달 시 단가 조정·참여 제한), 이상 패턴 탐지·캠페인 정지·전환 무효화, 공짜 소진율·예측 오차 모니터링.
4 · 광고주 성과 대시보드노출·클릭·전환·전환율·전환당 비용·과금액·잔여 예산. 전환 유형별 실적, 자연 vs 광고 기여·확정 vs 검증 대기 구분, 필터·다운로드, 전환 0 기간 과금 0원 확인·과금 근거 조회.
5 · 운영·정산·정책카테고리·지면·셀러 등급·품질·한도 설정, 전환 검증·승인·무효·환불 조정, 공짜 소진율·마진·기회비용 파일럿 기준 비교, 게이트 충족 시 확대·미달 시 자동 축소, 성과형 vs CPD 분리 집계(잠식 확인).
6 · 단계적 출시 로드맵파일럿 대상·기간·사전 KPI 승인 → 종료 후 성장·건전성 지표로 확대/유지/축소 결정. 공짜 소진율·마진 하회 시 한도 축소, 외부 광고주·CPA/건수 보장은 Phase 2, 대형 CPD는 범위 제외·유지.
