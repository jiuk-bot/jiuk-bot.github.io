아웃바운드 발굴 자동 리포트 · 기업 조회

비즈니스 시그널(투자·계절성·채용·광고 노출량 등)을 ① 스코어링 엔진으로 점수화해 오늘 연락할 회사를 추천하고, 기업명을 입력하면 회사 개요·마케팅 현황·토스 핏·접근 전략·다채널 컨택까지 한 화면에서 — 검색 → 파악 → 컨택. (스코어링·조회 엔진은 실제 동작, 데이터는 예시)

리포트는 날짜 기준으로 고정됩니다 — 같은 날엔 같은 리스트, '이전/다음 날'로 날짜별 시그널 변화를 봅니다(클릭마다 랜덤 X). 각 행에서 바로 컨택 채널을 열거나 📇 전체 채널로 상세 조회로 넘어가고, ⬇ 엑셀 다운로드로 컨택 링크 포함 리스트를 내려받습니다.
실데이터 연동 — 뉴스·LinkedIn·광고 라이브러리를 매일 수집해 시그널을 채우면 실무 리포트가 됩니다(수집은 백엔드 필요). 회사는 실제 기업이라 홈페이지·문의·컨택 버튼이 진짜로 연결되지만, 시그널·점수는 툴 로직 시연용 가상 시나리오이며 해당 기업의 실제 상황이 아닙니다.

무엇을 보여주나 — BDR이 콜 전에 필요한 회사 개요·마케팅 현황(현재 매체·추정 예산·타깃)·비즈니스 시그널·토스 Ads 핏·접근 전략·콜 전 체크리스트를 한 화면에 정리하고, 담당자 컨택(LinkedIn·리멤버·홈페이지·구글·네이버)과 마케팅 채용·조직 확인(원티드·사람인·잡코리아·잡플래닛·LinkedIn Jobs·채용 페이지) 채널을 전부 실제 검색 링크로 연결합니다.
예시 12개 기업은 실제 기업이라 홈페이지는 실제 도메인으로 바로 이동하고 문의·LinkedIn·채용 버튼도 실제로 연결됩니다. 그 외 기업명도 입력하면 조회됩니다(홈페이지는 공식 사이트 검색으로 연결). 시그널·점수·개요·예산·매체는 툴 로직 시연용 가상 추정이며 해당 기업의 실제 상황이 아닙니다.
