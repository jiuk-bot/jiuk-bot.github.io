리포트는 날짜 기준으로 고정됩니다 — 같은 날엔 같은 리스트, '이전/다음 날'로 날짜별 시그널 변화를 봅니다(클릭마다 랜덤 X). 각 행에서 바로 컨택 채널을 열거나 📇 전체 채널로 상세 조회로 넘어가고, ⬇ 엑셀 다운로드로 컨택 링크 포함 리스트를 내려받습니다.
데모 버전 — 여기 발굴 큐 20곳은 토스 Ads 타깃 핏(소비자·2030·광고 집행) 실제 기업으로, 뉴스·마케팅 채용·계절성을 매일 자동수집해 스코어링합니다(각 행 📇 전체 채널 →에서 근거 기사·공고 링크 확인). 홈페이지·문의·컨택 버튼은 전부 실제 회사 공식 홈페이지로 연결됩니다. (임의 기업 즉석 검색은 서버 배포 시 활성화)

무엇을 보여주나 — BDR이 콜 전에 필요한 회사 개요·마케팅 현황(현재 매체·추정 예산·타깃)·비즈니스 시그널·토스 Ads 핏·접근 전략·콜 전 체크리스트를 한 화면에 정리하고, 담당자 컨택(LinkedIn·리멤버·홈페이지·구글·네이버)과 마케팅 채용·조직 확인(원티드·사람인·잡코리아·잡플래닛·LinkedIn Jobs·채용 페이지) 채널을 전부 실제 검색 링크로 연결합니다.
실무에 바로 쓰는 방식 — 아무 실제 회사명을 넣고, 각 시그널의 🔗 확인으로 메타 광고 라이브러리·투자 뉴스·채용·구글 트렌드를 직접 보고 사실인 것만 체크 → 점수는 확인분만으로 계산됩니다(추정·허위 0). 회사 규모·투자·집행 매체도 팩트 소스 링크(더브이씨·기업정보·광고 라이브러리·뉴스)로 직접 확인하고, 담당자는 리멤버·직무별 좁혀찾기로 확보합니다. 모든 버튼은 실제 연결. 자동 수집·일일 리포트화는 백엔드 연동이 다음 단계입니다.
