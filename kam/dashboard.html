🔒 파트너 데이터 보안 관리 (실제 운영 시) — 데이터 유출 가능성을 원천 차단하기 위해, 대시보드는 담당자 로컬 환경(개인 노트북)에서만 구동(localhost)하며 외부 서버·클라우드에 파트너 데이터를 저장·배포하지 않습니다. API 토큰·인증키는 .env로 분리해 환경변수로 관리하고, 데이터는 읽기 전용(read-only)·접근 권한 최소화 원칙으로 다룹니다.
